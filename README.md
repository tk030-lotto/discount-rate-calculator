# 割引率らくらく計算

複数の割引を順番に適用したときの、**実際の支払額と最終的な割引率を簡単に確認できる無料・登録不要のWebツール**です。

「50%OFFのあと30%OFFだから、合計80%OFF」というような勘違いを避け、各段階の計算過程を見える形にすることを目的とします。

## コンセプト

割引率を単純に足し算するのではなく、**割引後の価格に次の割引を順番に適用する**という考え方を、計算結果と途中経過で分かりやすく確認できるようにします。

## 主な特徴

- **無料・登録不要**: ログインなしですぐ利用できます。
- **ブラウザ完結**: 基本的な計算をブラウザ内で処理します。
- **連続割引に対応**: 50%OFF → 30%OFFのような複数段階の割引を順番に計算できます。
- **計算過程を表示**: 各割引を `× 0.5`、`× 0.7` のように表示し、価格がどう変化したか確認できます。
- **最終支払額を表示**: すべての割引適用後の金額を確認できます。
- **実質割引率を表示**: 複数割引を適用した結果、元価格から実際に何%割引になったかを表示します。
- **勘違いしやすいケースを分かりやすく表示**: 「50%OFF + 30%OFF = 80%OFF」ではないことを直感的に確認できます。
- **スマートフォン対応**: スマートフォンでも使いやすいUIを想定します。

## 計算例

```text
通常価格       10,000円

50% OFF
  × 0.50
  ↓
 5,000円

さらに30% OFF
  × 0.70
  ↓
 3,500円

最終支払額      3,500円
実質割引率       65%
```

この場合、

```text
50% + 30% = 80%
```

ではありません。

元価格10,000円に対し、最終価格が3,500円なので、実際の割引は65%です。

## 基本計算

割引率を `r` とした場合、割引後価格は、

```text
割引後価格 = 現在価格 × (1 - r)
```

で求めます。

複数の割引を順番に適用する場合は、各割引を順番に適用します。

例：

```text
10,000 × 0.50 × 0.70
= 3,500円
```

最終割引率は、

```text
最終割引率 = (1 - 最終価格 ÷ 元価格) × 100
```

で求めます。

## 利用イメージ

```text
通常価格を入力
      ↓
割引率を1つ以上入力
      ↓
各段階の価格を計算
      ↓
最終支払額を表示
      ↓
実質的な最終割引率を表示
```

## 対象

- 店内割引 + 商品別割引など、複数の割引を計算したい場合
- セール価格を確認したい場合
- クーポンや追加割引を適用した後の金額を確認したい場合
- 割引率の計算方法を確認したい場合

## プライバシー

基本的な計算処理はブラウザ内で完結することを基本方針とします。

入力した価格や割引率を外部サーバーへ送信することを前提としません。
